# Treino de Rotina de SQL

Este repositório contém materiais para aprender e praticar SQL.

## 📚 Arquivos Disponíveis

### 1. Aula SQL.sql
Arquivo com conceitos teóricos e exemplos de SQL, incluindo:
- Funções matemáticas, strings e datas
- Funções estáticas (COUNT, SUM, AVG)
- Agrupamento com GROUP BY
- Cláusula HAVING
- Ordenação com ORDER BY
- Uso de DISTINCT

### 2. Exercicios SQL.sql
Arquivo prático com **40+ exercícios** organizados em 14 partes:

1. **Criação de Tabelas (DDL)** - CREATE TABLE
2. **Inserção de Dados** - INSERT
3. **Consultas Básicas** - SELECT
4. **Operadores e Filtros** - WHERE, LIKE, BETWEEN, IN
5. **Ordenação** - ORDER BY
6. **Funções de Agregação** - SUM, AVG, COUNT, MAX, MIN
7. **Agrupamento** - GROUP BY
8. **Filtros em Agregações** - HAVING
9. **Junção de Tabelas** - INNER JOIN, LEFT JOIN
10. **Subconsultas** - Subqueries
11. **Atualização de Dados** - UPDATE
12. **Exclusão de Dados** - DELETE
13. **Consultas Avançadas** - Combinação de múltiplos conceitos
14. **DISTINCT** - Eliminação de duplicatas

**Plus:** 3 desafios extras para treino avançado!

## 🚀 Como Usar

1. **Estude a teoria**: Comece lendo o arquivo `Aula SQL.sql` para entender os conceitos
2. **Pratique**: Abra o arquivo `Exercicios SQL.sql` e tente resolver cada exercício
3. **Verifique suas respostas**: As soluções estão comentadas logo após cada exercício
4. **Dica**: Tente resolver sem olhar a solução primeiro!

## 💡 Pré-requisitos

- Um banco de dados SQL (MySQL, PostgreSQL, SQL Server, SQLite, etc.)
- Um cliente SQL ou interface de linha de comando
- Conhecimento básico de comandos SQL

## 📖 Estrutura dos Exercícios

Cada exercício segue este formato:

```sql
-- Exercício X: Descrição do que fazer

-- SOLUÇÃO:
/*
-- Código SQL da solução (comentado)
*/
```

As soluções estão comentadas para você tentar resolver primeiro. Descomente para testar!

## 🎯 Objetivo

Este repositório foi criado para ajudar no treino contínuo de SQL, cobrindo desde conceitos básicos até operações mais avançadas.

Bom estudo! 🚀📊
